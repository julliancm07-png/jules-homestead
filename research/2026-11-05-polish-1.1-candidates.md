# Polish pass 1.1: candidate mods & resource packs (2026-11-05)

Request (Jules): "polish this and add whatever mods and resource packs you can find that improve this experience".

## Method
1. Modrinth search, sorted by downloads:
   * every Fabric mod for 26.1.2: 1000 checked, 880 not in the pack;
   * every resource pack for 26.1.x: 600 checked, 583 not in the pack.
   Raw lists were kept in the session scratchpad; the deciding facts are below.
2. Filtered by theme: homestead, cozy, winter/weather, farming, decor, ambience, QoL, performance.
3. Rejected anything that would be a second owner of a system (docs/design.md), anything that doesn't fit the
   vanilla+ tone, PvP, HD or full texture overhauls, and server-admin tools.
4. Probed each pick: 26.1.2 Fabric build, licence, sides, newest release (`/project/<slug>/version`).
5. Jar-level dependency validation follows (`tools/validate.py`). Resource packs are now also checked for
   pack format 84.

## Considered and not used
* **Still no 26.1.2 Fabric build:** Supplementaries, Handcrafted, Chipped, Another Furniture, Decorative Blocks, Let's Do (Bakery, Vinery, Candlelight, Meadow), Farmer's Respite, Brewin' and Chewin', Expanded Delight, Cultural Delights, Polymorph.
* **Cooking for Blockheads:** its unpowered fridge and fuel oven would undercut the powered-appliance design (food in a "fridge" that still spoils). Revisit only with those blocks disabled.
* **Second owner of a system:**
  * Snow! Real Magic and Snow (snowlogging), because homestead-core and Snow Under Trees own snow;
  * CTOV, Villages & Pillages and Lio's villages, because Towns & Towers owns villages;
  * Biomes O' Plenty, Regions Unexplored, Nature's Spirit and YUNG's Cave Biomes, because Terralith owns world generation;
  * EMI/REI, because JEI owns recipes;
  * Effectual, whose fire effects overlap Subtle Effects;
  * Veinminer and Tree Harvester, because Falling Tree owns tree felling.
* **Tone:** Better Combat, magic and RPG mods, Artifacts, Enhanced Visuals, horror packs and PvP resource packs.
* **Clashes with Recolourful + Spatial GUI:** dark-mode GUI packs, Shrimp's Immersive Interfaces, Smooth GUI and Blur+.
* **Texture overhauls** (Faithful, Stay True style): keep the vanilla look.
* **Fresh Food:** overlaps TheOne's Eating Animation on the same item models.

## Tried and removed
* **LightspeedRE 2.0.5** (resource-pack cache and "high-concurrency" start-up): it finishes loading early on its own
  threads ("Trying to complete load early..."), and the integrated server then started before Xaero's library had
  frozen its registry: same crash as ModernFix ("Registry is not frozen yet!"). Removed.
* **ModernFix-mVUS 5.27.19** (community fork of ModernFix for 26.1.x): in the full client, resource packs failed to load
  with "zip file closed" errors during the start-up reload. Xaero's library then never finished initialising, and the
  integrated server crashed ("Registry is not frozen yet!"). The same instance without ModernFix passed. Removed.

### Considered and not used
* **Star and sky mods** (Nicer Skies, Spyglass Astronomy, Smooth Skies, HD sun and moon packs, Better Clouds): Dramatic
  Skys already draws its own night skybox, stars and sun/moon (`sky1_stars`, `sky3_night`, `sky5_night`), and shaders
  draw their own sky. A second sky owner would be hidden or clash.
* **Darkness mods** (Enhanced Darkness and similar): "built for horror" and overrides the brightness slider; against the
  cozy brief and an accessibility loss. Darker, moon-phase nights are offered through the shader presets instead.
* **Better Animations Collection:** reshapes the same mob models that Fresh Animations (EMF) owns.
* **Fancy Door Animations:** FWA covers doors and much more.
* **Smooth GUI, Blur+:** screen-open animations clash with Spatial GUI's own panel animation.
* **Chat Animation, Immersive Hotbar, Smooth HUD:** overlap Smooth Scroll's chat and hotbar smoothing; one mod per
  widget avoids two sets of changes to the same screen code.
* **Better Block Entities:** big FPS gain for chests and signs, but it bakes block entities into chunk meshes, so it
  risks clashing with FWA's chest animation and ETF/EMF block-entity textures (not tested). Revisit if FPS on Jules' PC
  is a problem.
* **zFastNoise:** overlaps C2ME's noise optimizations.
* **Fast Item Frames / Fast Paintings:** small gains, both need the server too, extra surface.
* **Leawind Third Person, smooth F5 mods:** change how the third-person camera behaves, not just its smoothness.
* **CozyUI+, Menu Buttons of Stone, Cozy Wooden UI, dark GUI packs:** modern-grey, stone-only, chest-only or dark
  themes; Homestead GUI fits the homestead wood-and-stone look best.

### Built-in packs (checked while adding A Good Place)
Our shipped `options.txt` lists resource packs explicitly, which drops built-in packs that a mod registers as "enabled by
default". A scan of every jar for `resourcepacks/<name>/` and its activation type found only one such pack: A Good
Place's default animations. `tools/package.py` now lists it (`BUILTIN_DEFAULT_PACKS`). Continuity, Subtle Effects, Fish of
Thieves and Soft Imprints register opt-in packs only.
